# Session Handoff — Godot FPS Studio

## Starting request and constraints

The user is building a custom Godot fork and editor for Half-Life-inspired FPS games. macOS on Apple Silicon is the primary editor platform; exported games should support Windows, macOS, and Linux. The long-term plan includes modular editor architecture, Hammer-style level tools, a GDScript Action Director timeline, and Play in Editor / God Mode.

The user clarified that the goal is a distinct, standalone FPS Studio editor and engine fork with its own name/branding, rather than a stock Godot editor with a few cosmetic changes. The desired editor layout is inspired by UE5, including a Content Browser and dockable right-side panels that can either stay open or collapse back to tabs.

The user asked for live 3D viewport FPS and RAM readouts. FPS must measure the 3D viewport itself, keep updating while the camera is still, and avoid relying on the editor-wide frame loop. The user also asked not to repeatedly reopen the editor; they said it is closed and most recently confirmed, “tohle se fakt povedlo” / “suprově to běží.” Keep it closed unless explicitly asked to run it.
